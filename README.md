# JS Dottignies Bar — Web/PWA
Conversion HTML/CSS/JavaScript du main.dart fourni.

- Copiez votre dossier Flutter `assets/logos/` dans `assets/logos/`.
- Exécutez `supabase/schema.sql` dans Supabase.
- Configurez les policies RLS.
- Renseignez Project URL et clé anon/publishable dans `js/config.js` (jamais `service_role`).
- Publiez le dossier sur GitHub Pages.

Fonctions converties : catalogue, catégories, panier, quantités, paiement espèces + monnaie, carte/SumUp simulé, PIN admin 2026, statistiques du jour, prix vente/achat, responsive et PWA.
